# 🌐 webserv

`webserv` is a custom HTTP server project built to explore networking, request handling, and web fundamentals in C++.

The goal is to build a minimal but functional server that understands the basics of HTTP communication: requests, responses, routing, and client-server interaction.

## ⚙️ Concepts covered

- HTTP request parsing
- Response generation
- Socket programming
- Server lifecycle and client handling

## 🛠️ Build

```bash
make
./webserv config.conf
```

## 💡 Why this project matters

It connects low-level systems programming with the practical world of web services and teaches how a server turns network traffic into usable application behavior.

> The internet is just sockets with a lot of personality.
